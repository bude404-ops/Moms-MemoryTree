capabilities

What it can do now

The current foundation is built for safe iteration: app UI, domain model, local demo mode, provider boundaries, validation, and honest production gates.

🔐

Private by default

Family-scoped models, private storage architecture, signed media access, environment validation, and secret scanning.

🧬

Family-centered data

Families, people, members, relationships, memories, timeline events, custodians, and storage usage are separate concepts.

🎞️

Memory preservation

Stories support type, category, date, location, associated person, tags, privacy, and private media metadata.

📈

Cost visibility

Storage economics estimate usage, cost, quota, addon, revenue, and margin without pretending invoices exist.

🧓

Legacy custody

Legacy custodians can be modeled now, while future activation remains blocked until verified workflows exist.

✅

Validation gate

Lint, tests, migrations, RLS checks, environment checks, live-harness checks, deployment checks, secrets, and build.
