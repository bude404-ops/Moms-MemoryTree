# Stage 9 — Legacy and Archive Baseline

## Status

Complete as a controlled architecture baseline. Legacy activation, notifications, archive worker, and downloadable bundle generation remain future implementation.

## Legacy Rules

- No automatic death detection.
- No password transfer model.
- Custodians do not automatically receive private memories.
- Legacy access requires explicit permissions.
- Legacy Mode requires future controlled verification.
- Legacy actions must be audited.

## Current Foundations

- legacy messages
- legacy custodians
- legacy permissions
- legacy status fields
- archive export tracking
- backup record tracking
- audit log foundation

## Archive Export Rules

Future archive exports must include only authorized content:

- family tree
- relationships
- timeline
- memories
- original media where permitted
- metadata
- transcripts/tags only if allowed
- legacy messages only when unlocked

Exports must not bypass privacy, descendant, specific-person, or legacy permissions.

## Dashboard Implications

The dashboard may show:

- legacy architecture status
- custodian setup status
- archive export foundation status
- blockers and next actions

The dashboard must not claim:

- legacy mode is live
- archive downloads are ready
- backups are verified
- custodians can already unlock memories

## Validation Gates

- permission tests
- audit expectations
- future live export manifest tests
- future restore/import tests

## Stage 9 Decision

Legacy and archive foundations are dashboard-ready as status/roadmap surfaces, not as live production claims.
